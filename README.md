# 给十年后的我

一个 Win98 风格的"时间胶囊"手机网页（H5）：12 岁的你写了个小程序，问问十年后的自己过得好不好，最后送你一颗星星、一片星空。

- 在线地址：https://suyfdong.github.io/ten-years/
- 代码仓库：https://github.com/suyfdong/ten-years
- 整个作品只有一个文件：`index.html`（不依赖任何外部库、图片或字体）

## 灵感与思路

灵感来自抖音上一个电脑版的 Win98 弹窗视频。我们只借它的**形式和感觉**，做成竖屏手机版，方便在微信里打开、转发。

打动人的三点，也是我们复刻的重点：

1. **怀旧的系统界面**：Win98 桌面、蓝色标题栏弹窗、像素图标、任务栏、扫描线。
2. **笨拙又真诚的孩子语气**：所有文案都是 12 岁的口吻。
3. **前面的问题在结尾被接住**：中间问"你有自己的望远镜了吗"，结尾回应"没有望远镜也没关系，抬头就能看星星呀"。

**关于版权**：流程、风格和魔术效果参照原视频，但台词全部重新原创；背景音乐也是用代码现场合成的原创八音盒旋律，不使用任何现成歌曲。

## 流程（约 2 分钟）

1. **桌面**：中间是文件 `给十年后的我.vbs`，下方有跳动的箭头和"点这里打开"。
2. **像素问候**：小窗口一个个弹出，每个里面是一个彩色像素大字，拼成"你好啊 未来的我"。
3. **自我介绍**：例如"我是12岁的你！"。
4. **5 道问答**：前 4 题选"是 / 否"，各有回应；第 5 题"那你现在开心吗？"，选"开心"或"不太开心"都会进入魔术。
5. **魔术**：一个"魔术·看好啦"小窗口错位叠加几百次，像病毒一样拖出一条带子，画出五角星（约 14 秒）；然后一颗立体金星一层层叠出来，弹出"当当当！☆送你一颗星星☆"。
6. **弹窗雨**（约 18 秒）：按顺序弹出几十个关心的话，从日常叮嘱慢慢走到心里话，最后一个是"我会一直在这里，等你回来看我"。
7. **衔接**：所有窗口快速关掉，接着弹出"最后再送你一片星空！我们先把灯关掉～"，点"关灯"后屏幕变黑。
8. **星空**：满天星星从黑暗中亮起，还有闪烁的十字星、从深处飞出的星星、星云和流星；最后弹出结尾那句话，并显示"再看一遍"。

## 关键设计决定

| 问题 | 做法 |
|---|---|
| 弹框要不要都点？ | 问答题必须点（要做选择）；说话类弹框按字数停留几秒后自动往下走，也可以点击跳过 |
| 魔术怎么做 | 不是拖动窗口留下的残影，而是在 canvas 上把同一个小窗口沿五角星路径错开 2.2px 反复"盖章"；按时间推进，不受手机刷新率影响 |
| 节奏 | 画星星约 14 秒（慢慢起笔、越画越顺、收尾不拖）；弹窗雨间隔 0.7 秒逐渐缩短到 0.4 秒，大窗口停 1.3 秒 |
| 关灯闪桌面的 bug | 在黑幕下关闭所有过渡动画，瞬间藏好桌面，等星空画出第一帧再撤黑幕 |
| 背景音乐 | Web Audio 合成的八音盒：66 BPM，和弦 F–G–Em7–Am7–Dm7–G–Cmaj7–C，带混响和轻微"旧磁带"走音；关灯时压低，星空亮起时回来 |
| 一打开就有音乐 | 浏览器规定用户交互前不能出声。做法：页面加载就把音乐准备好；在微信里收到 `WeixinJSBridgeReady` 时解锁（iPhone 微信基本可行，安卓看版本）；其他情况在用户第一次碰屏幕任何地方时解锁 |

## 怎么改内容

所有文案都在 `index.html` 开头的 `STORY` 对象里，改文字不用碰代码：

- `greeting`：像素大字问候
- `questions`：前 4 道题和"是 / 否"的回应
- `last` / `lastYes` / `lastNo`：第 5 题和回应
- `magicTips`：画星星时冒出的提示
- `rain` / `rainBig` / `rainLast`：弹窗雨的内容（按顺序弹出）
- `lightsOff` / `ending`：关灯提示和结尾那句话
- `bgm`：想换成自己的音乐，把 mp3 放在同目录，这里填文件名，如 `"bgm.mp3"`；留空就用内置八音盒

## 本地预览

```bash
cd /Users/susu/idea/zhangda
python3 -m http.server 8765
```

- 电脑上打开 `http://localhost:8765/`。
- 手机连同一个 Wi-Fi，打开 `http://<电脑局域网 IP>:8765/`。查 IP：`ipconfig getifaddr en0`。
- 局域网地址只有同一个 Wi-Fi 下的设备能访问，不能拿来转发。

## 部署（GitHub Pages，免费、不用买域名）

首次部署（已完成，2026-10-28）：

```bash
cd /Users/susu/idea/zhangda
git init -b main
git add index.html .gitignore
git commit -m "..."
gh repo create ten-years --public --source=. --remote=origin --push
gh api -X POST repos/suyfdong/ten-years/pages -f "source[branch]=main" -f "source[path]=/"
```

开启后 1–2 分钟构建完成。查看状态：`gh api repos/suyfdong/ten-years/pages --jq .status`，显示 `built` 就是好了。

**以后更新**：改完本地文件后推送即可，同一个网址 1–2 分钟后自动更新：

```bash
git add index.html
git commit -m "说明改了什么"
git push
```

`.gitignore` 排除了 `.playwright-mcp/`（测试截图）和 `.claude/`，不会传上去。

## 在微信里使用

1. 把网址发到微信"文件传输助手"，在手机微信里点开。
2. 点右上角"···"，选"发送给朋友"或"分享到朋友圈"。

已知限制：

- `github.io` 在国内有时慢，偶尔会被微信拦截，提示"请复制链接到浏览器打开"。遇到时可以换 Netlify（app.netlify.com/drop 拖文件夹上传）再试。
- 分享卡片的标题是"给十年后的我"，缩略图和描述由微信自动生成。想自定义，需要公众号 JS-SDK，而那要求备案域名。
- 想长期、大范围传播：买域名 + 国内服务器 + ICP 备案（1–3 周）最稳。
